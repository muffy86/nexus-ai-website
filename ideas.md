# Design Philosophy: Cyber-Tech

**Core Principles:**
- High contrast dark backgrounds with electric accents
- Technical, futuristic aesthetic with glowing effects
- Terminal-inspired elements and code-centric design
- Diagonal cuts and asymmetric layouts for dynamic energy

**Color Palette:**
- Primary: Electric Blue `oklch(0.65 0.25 240)`
- Accent: Neon Green `oklch(0.75 0.2 180)`
- Background: Deep Navy `oklch(0.12 0.02 240)`
- Foreground: Near White `oklch(0.95 0.02 240)`
- Muted: Cool Gray `oklch(0.55 0.05 240)`

**Typography:**
- Headings: Space Grotesk (technical, geometric, bold)
- Body: Inter (clean, readable, professional)
- Code: JetBrains Mono (monospace, technical)

**Signature Elements:**
- Glowing borders with pulse animations on key elements
- Terminal-style code blocks with colored dots
- Floating stat cards with backdrop blur
- Diagonal section cuts for visual flow
- Grid patterns and tech-inspired backgrounds

**Interaction Philosophy:**
- Subtle glow effects on hover
- Smooth transitions (200-300ms)
- Pulse animations for primary CTAs
- Lift effects on cards (translateY -4px)

**Animation:**
- Glow-pulse for primary elements (2s infinite)
- Fade-in-up on page load with stagger
- Hover lift with shadow enhancement
- Smooth color transitions on interactive elements
